# 🌤️ Weather App

A responsive and interactive Weather Application built using **HTML, CSS, and JavaScript**. The application uses the **OpenWeatherMap API** to fetch and display real-time weather information for any searched city.

## 🚀 Live Demo

[View Live Demo](YOUR_VERCEL_URL)

## 📌 Features

- 🔍 Search weather by city name
- 🌡️ Displays current temperature
- ☁️ Displays current weather condition
- 💧 Shows humidity
- 💨 Shows wind speed
- 📅 Displays the current date
- 🌦️ Dynamic weather icons based on weather conditions
- 📆 Displays a 5-day weather forecast
- ❌ Shows a message when the city is not found
- 📱 Responsive design for desktop, tablet, and mobile devices
- ✨ Interactive and user-friendly interface
- 🔄 Supports searching using the Enter key

## 🛠️ Technologies Used

- **HTML5** – Structure of the application
- **CSS3** – Styling, responsive design, and glassmorphism UI
- **JavaScript** – Application logic and API integration
- **OpenWeatherMap API** – Real-time weather data
- **Google Material Symbols** – Weather and interface icons
- **Google Fonts** – Poppins font
